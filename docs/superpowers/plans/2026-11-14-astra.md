# 아스트라 (ASTRA) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 브라우저에서 링크 하나로 하는 정직한 판타지 뽑기 RPG — 소환(★1~★7, 천장 50), 3인 턴제 전투, 3챕터 30스테이지, 레벨업·겹치기 육성, 일일 미션, ★6 이상 등장 컷신.

**Architecture:** 게임 규칙(뽑기·전투·육성·저장·미션)은 화면과 분리된 순수 JS 모듈(`src/core`)이고 Vitest로 검증한다. 메뉴 화면은 DOM(`src/ui`), 전투와 소환 연출만 Phaser 씬(`src/game`). 캐릭터 그림은 좀비 생존자의 Canvas 2D 그리기 코드(`blob.js`)를 복사해 DOM 초상화와 Phaser 텍스처에 같이 쓴다.

**Tech Stack:** Vite 5, Phaser 3.90, Vitest 2, 순수 JS(ES 모듈), GitHub Pages.

**Spec:** `docs/superpowers/specs/2026-11-14-astra-design.md`

## Global Constraints

- 모든 UI 글자는 한국어, 짧고 쉽게(12살 대상). 버튼은 크게(최소 높이 52px).
- 세로 화면 기준 720×1280, 휴대폰 우선. Phaser `Scale.FIT`.
- 진짜 돈·결제·패키지 광고 화면은 어디에도 없다.
- 연출은 결과를 속이지 않는다: 소환 빛 색 = 그 소환의 최고 별, 바뀌는 연출 금지.
- 강화·레벨업·겹치기에 실패 없음, 영웅이 사라지는 일 없음.
- 번쩍임 효과는 설정 `flash` 기본 꺼짐. 꺼져 있으면 흰 화면 번쩍임·빠른 깜빡임 없이 연출한다.
- 소리는 합성음, 칩튠식 사각파 삐뽀 금지.
- 확률 ★1 40 / ★2 28 / ★3 18 / ★4 9 / ★5 4 / ★6 0.9 / ★7 0.1(%), 천장 50, 1회 100💎, 10+1회 1,000💎.
- 시작 3,000💎, 첫 클리어 일반 150💎·보스 1,000💎, 일일 미션 3개 × 100💎.
- 겹치기 최대 +5, 한 번에 능력치 +10%.
- 팀 최대 3명.
- 별 색: ★1 `#b8c2cc`, ★2 `#55d468`, ★3 `#5a9dff`, ★4 `#b56dff`, ★5 `#ffa33a`, ★6 `#ff4d4d`, ★7 `#ffe066`.

## Review Focus

1. 다이아가 모자랄 때 소환 → 버튼이 꺼져 있고 "다이아가 부족해요", 다이아는 절대 음수가 안 된다. (Task 3 테스트)
2. 깨진 저장·옛 버전 저장·잘못된 저장 코드 → 게임이 멈추지 않고 기본값/거절 메시지. (Task 4 테스트)
3. 팀이 1~2명이거나 0명일 때 → 1~2명이면 그대로 싸우고, 0명이면 모험 버튼에서 "편성에서 영웅을 넣어 주세요". (Task 5 테스트 + Task 7)
4. 기절·잠·석화 상태이거나 이미 쓰러진 영웅의 스킬 버튼 연타 → 스킬은 한 번만 예약되고, 행동할 수 없으면 쿨타임이 그대로 남는다. (Task 5 테스트)
5. 자정이 지나 다시 열었을 때 → 일일 미션이 새 날로 초기화, 이미 받은 보상은 다시 못 받는다. (Task 6 테스트)
