# 아스트라 v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 쿠키런 킹덤 수준의 확률·별 세기·시작 경험·모험(전투력/별 3개/새 적 소개)·그림(맵/뽑기/살아 있는 마을 로비).

**Architecture:** 규칙 변경은 `src/core`·`src/data`에 TDD로, 그림은 Canvas 2D 모듈(`src/game/backgrounds.js`, `src/render/town.js`)과 Phaser 씬(`SummonScene` 다시 쓰기). 각 그림은 스크린샷으로 확인.

**Tech Stack:** 기존과 같음(Vite 5, Phaser 3.90, Vitest 2).

**Spec:** `docs/superpowers/specs/2026-11-14-astra-v2-design.md`

## Global Constraints

- 확률 {1:45, 2:34, 3:15, 4:5, 5:0.85, 6:0.12, 7:0.03}, 천장 PITY=300(300번째 확정), 10+1에 ★4 이상 1명 보장.
- 별 배율 [_, 1, 1.3, 1.7, 2.2, 2.9, 8.7, 17.4], 최대 레벨 [_, 10, 15, 20, 25, 30, 40, 50].
- 번쩍임은 `settings.flash`일 때만. 깜빡이는 반복 효과 금지(천천히 밝아졌다 어두워지는 것은 주기 1.5초 이상).
- UI 글자는 한국어, 12살이 읽기 쉽게.
- 쿠키런 킹덤의 그림·이름·캐릭터는 쓰지 않는다.

## Review Focus

1. 옛 v1 저장(최대 레벨을 넘은 ★1 Lv30, pity 49, stars 없음)을 불러와도 멈추지 않는다 → 레벨은 별별 최대로 깎이고, 기존 cleared는 별 1개로 인정. (Task 1 테스트)
2. 소환권이 있는데 다이아 0 → 소환권 소환은 된다. 소환권 0이면 소환권 버튼이 없다. (Task 2 테스트 + Task 5)
3. 10+1 결과가 ★4 이상 보장 + 천장이 같은 묶음에서 겹쳐도 결과 11개, 다이아 1000만 빠진다. (Task 2 테스트)
4. 별 3개 조건: 패배·나가기에는 별이 0개이고, 다시 깨서 별이 줄어도 기록은 최고값을 유지한다. (Task 3 테스트)
5. 로비 캔버스 애니메이션이 다른 화면으로 가면 멈춘다(requestAnimationFrame 누수 없음). (Task 6)
